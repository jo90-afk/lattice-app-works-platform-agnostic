# Resume Lattice

Resume from `state/current.json`, the portfolio registry, and current project artifacts. Run `python3 scripts/lattice.py status`, then select the highest-priority ready frontier action within WIP limits.

Use the action's scoped context rather than reconstructing project history. Claim it, execute under the named role, submit or review through the guarded runtime, and recompute the frontier. Stop only when the frontier is empty, capacity is full, a genuine commitment is pending, or an exact Principal exception blocks progress.

Report objectives, accepted milestones, open commitments, exceptions, and truth-ledger transitions. Do not report a fabricated backlog or ask for routine status acknowledgement.

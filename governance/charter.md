# Agency Charter

Lattice App Works is a persistent, multi-project software agency. It converts confirmed goals and current project state into a small derived action frontier, coordinates specialized agents within strict ownership boundaries, verifies changes independently, and interrupts the Principal only at retained consequence boundaries.

The agency does not equate activity with progress. It stores durable truth and evidence, not speculative task inventories. The absence of a frontier action is a valid state: it can mean the project is complete, paused, awaiting a true external commitment, or missing an authorized objective.

## Authority

The Principal owns agency and project mandates, portfolio priority, material cost and data-policy changes, irreversible or externally consequential actions, material risk acceptance, and production launch. The Director schedules within those boundaries. Domain agents own their artifacts. Independent reviewers determine whether readiness conditions are satisfied. Assurance accepts milestone transitions only after the runtime's predicates pass.

No agent approves its own output. No project capsule can redefine agency roles or escalation. No host adapter can widen authority.

## Persistence boundary

Lattice persists:

- current objectives and milestone conditions;
- versioned requirements, constraints, decisions, artifacts, and world-state truths;
- evidence-backed submissions and independent reviews;
- actual commitments, unresolved exceptions, and meaningful state transitions.

Lattice derives or discards:

- possible next actions;
- execution briefs and agent plans;
- reviewer assignments;
- routine remediation steps;
- status prose that can be reconstructed from state.

This boundary keeps the agency auditable without making its own administration the dominant workload.

## Portfolio boundary

Projects remain isolated by stable ID. Each has independent product state, evidence, truth ledger, and release history. Portfolio order controls scheduling but does not make one project's claim, exception, or design decision valid in another.

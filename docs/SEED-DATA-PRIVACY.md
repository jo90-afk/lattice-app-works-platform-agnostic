# Seed-data privacy

This distribution is intentionally a clean seed. It contains no real Principal identity, personal project timeline, approvals, notes, life records, contacts, or user-generated source material.

Before using Lattice:

1. Initialize the seed with a non-sensitive Principal alias and a stable project ID.
2. Confirm a new project mandate before creating domain artifacts.
3. Keep real project capsules private when they contain personal, confidential, regulated, or credential-bearing material.
4. Regenerate hosted source packs only from the intended current repository state.

The generic validator checks for common credential, email-address, and phone-number patterns. It cannot decide whether an ordinary phrase becomes identifying in context; review before publishing.

# Claude adapter

For Claude Code, start in this repository's root. CLAUDE.md imports AGENTS.md, so Claude Code receives canonical governance without a duplicate policy copy.

Use repository files for durable state. Do not rely on Claude memory, chat history, or auto-generated notes as the record of a gate, handoff, verification, or project decision.

For a file-upload-only Claude session, generate the desired project's pack under exports/chatgpt-work/<project-id>/ and upload its labelled source pack. State that the host must follow AGENTS.md source headings, preserve project isolation, and return changes as exact file updates.

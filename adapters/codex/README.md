# Codex adapter

Open or start Codex in this repository's root directory. The canonical AGENTS.md is deliberately kept at the root so Codex discovers the durable Lattice guidance with the project.

Use separate chats for distinct outcomes. Before a specialist task, give Codex the role name, one project ID, one ready work order, named inputs, and the owned output path. Use a fresh chat or delegated context for independent verification and Assurance.

Do not add a .codex policy fork. Host preferences may be local to a user, but agency policy remains in AGENTS.md, agency.yaml, agents/, and governance/.

    python3 scripts/lattice.py status
    python3 scripts/lattice.py validate
